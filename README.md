# cuddle-lamp

Приложение с генеративным звуком для фокуса, отдыха и сна. Звук синтезируется на устройстве по описанию сцены. В плеере можно выбрать сцену, настроить её звучание и поставить таймер.

Сейчас в разработке версии для iOS и Android. Тестовый экран можно запустить без сборки Rust.

## Что в репозитории

- `src/` — общий плеер на React Native.
- `core/` и `cpp/` — звуковое ядро на Rust и мост к плееру.
- `ios/` и `android/` — мобильные оболочки и аудиовывод.
- `scenes/` и `studio/` — сцены в JSON и веб-студия для их настройки.
