# План реализации тонов сольфеджио и фигур Хладни

Добавить в iOS-приложение сцену «Тоны сольфеджио» с девятью пресетами **174, 285, 396, 417, 528, 639, 741, 852 и 963 Гц**. При выборе пресета приложение перестраивает чистый тон и плавно переводит песок к рисунку, который даёт одна и та же виртуальная пластина на выбранной частоте. Начальное значение — 528 Гц.

## 1. Рассчитать девять фигур для одной пластины

- Начать с тонкой алюминиевой пластины 230 × 290 × 0,8 мм с шарнирным опиранием по четырём краям. Для первого расчёта взять модуль Юнга 69 ГПа, плотность 2700 кг/м³, коэффициент Пуассона 0,33 и относительное модальное затухание 0,008. Точечное возбуждение приложить в координатах 0,31 ширины и 0,43 высоты от одного угла. Предварительный расчёт с такими параметрами дал девять различных распределений областей слабой вибрации, в том числе для 396 и 417 Гц.
- Рассчитать установившийся вынужденный отклик на каждой из девяти точных частот по модели тонкой пластины Кирхгофа — Лява. Использовать сумму мод с учётом их возбуждения в заданной точке и затухания. Для размещения песка брать области малой амплитуды отклика внутри пластины. Сохранить параметры модели и воспроизводимый способ расчёта. [Экспериментальная работа о реконструкции фигур Хладни](https://doi.org/10.1121/1.4916704)
- Перед интеграцией визуала собрать контактный лист всех девяти фигур. Проверить форму, читаемость и достаточность отклика. При необходимости настроить параметры одной пластины для всех девяти частот. Если доступна физическая установка, сверить фигуры со съёмкой пластины с теми же параметрами.

- Добавить в Rust слой `tone` и сцену `scenes/solfeggio.json`. Использовать существующий синусоидальный осциллятор, `Smoothed` для перестройки частоты с сохранением фазы и штатные плавные старт и остановку. Подключить слой к каталогу и к проверке, прослушиванию и экспорту сцен в веб-студии. [Правила ядра](../core/AGENTS.md) · [Каталог сцен](../src/player/catalog.ts) · [Веб-студия](../studio/studio.ts)
- Показать девять доступных пресетов в герцах. Использовать штатные команды плеера, таймер, фоновое воспроизведение и сохранение настроек сцены. Хранить подтверждённый выбор в ядре и передавать его через снимок плеера. Из этого значения брать герцы для подписи и ключ фигуры для рендера. При смене пресета на паузе обновлять рисунок и начинать следующее воспроизведение с выбранной частоты. ## 3. Реализовать переход между фигурами

- Использовать имеющийся визуал как ориентир по плавности. Выбрать внешний вид, количество и способ движения песчинок по результатам прототипа. Подключить отрисовку отдельным модулем к нативному визуалу iOS и сохранить локальные правки сцены «Отдых» при интеграции. [Черновик фигур](../ios/Drafts/ToneGrains.cpp) · [Нативный визуал](../ios/CuddleLamp/LampSceneComponentView.mm)
- По подтверждённой частоте направлять песок к областям слабой вибрации новой фигуры. При повторном переключении продолжать движение из текущего состояния. На постоянной частоте рисунок должен стабилизироваться. При включённом «Уменьшении движения» сразу показывать целевую фигуру. Проверить плавность на iPhone и останавливать покадровую отрисовку после оседания песка.

## Критерии готовности

- В приложении доступны все девять пресетов и девять рассчитанных фигур. Для каждой частоты результат воспроизводится при повторном выборе, восстановлении настроек и смене направления переключения.
- В WAV частота каждого пресета совпадает с заданной в пределах 1 Гц. На устройстве старт, пауза и перестройка между 174 и 963 Гц проходят без слышимых щелчков.
- Быстрые повторные переключения, включая 396 ↔ 417 Гц, сохраняют непрерывность движения песка. Визуал корректно обновляется на паузе, после возврата из фона и при «Уменьшении движения».
- Проходят `cargo test --workspace` из `core/`, включая проверку аудиопотока, `npm run type-check`, сборка веб-студии и сборка iOS. К результату приложены контактный лист и краткая запись переключений на iPhone.
