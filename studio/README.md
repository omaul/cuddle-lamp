# Студия сцен

Выберите одну из сцен проекта или откройте свой JSON. После правки нажмите
«Проверить и применить». Студия проверит сцену через Rust-ядро, а во время
воспроизведения движок плавно переключится на новую версию.

Ручки и громкость меняют предпрослушивание. Чтобы сохранить новое положение
ручки как значение по умолчанию, укажите `default` от 0 до 1 в соответствующем
объекте `knobs`, примените изменения и скачайте JSON.

## Локальный запуск

```sh
rustup target add wasm32-unknown-unknown
cd studio
npm ci
npm run dev
```

Откройте адрес, который напечатает Vite (обычно <http://localhost:5173>).
Команда `npm run dev` сначала собирает Rust-ядро в WebAssembly. Если цель Rust
отсутствует, команда выведет инструкцию по установке до запуска Vite.

Команда `npm run build` проверяет TypeScript, собирает ядро и записывает готовый
сайт в `studio/dist`. Его можно открыть локально через `npm run preview`.
Для звука нужен браузер с поддержкой WebAssembly и AudioWorklet.

## GitHub Pages

В настройках репозитория откройте **Settings → Pages → Build and deployment**
и выберите **GitHub Actions** в поле **Source**. Workflow
**Студия сцен · GitHub Pages** запускается при пуше в `main`. Его также можно
запустить вручную во вкладке **Actions**.
